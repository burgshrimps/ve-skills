Read INFO/AF as population frequency and every one of the 68 variants scores as common — including all 68 that segregate with the disease. The filter does not merely fail. It inverts: the more relatives carry a variant, the more common it looks, and the faster it is discarded.

ve-frequency
68 → NO_DATA

refused, each with a named reason: cohort AF, not population AF. The abstention travels downstream as data.

Build

Read from ##reference and contig lengths, never assumed. Our data is b37; gnomAD v4 is GRCh38-only. Unknown build → NO_DATA.

Liftover

Vendored 285 KB Ensembl chain, stdlib only. 4/4 against Ensembl REST and gnomAD's own liftover. 32.5% of blocks are minus-strand.

Absence ≠ rarity

Not-found at a covered site is bounded by ~3/AN. Not-found at an uncovered site is NO_DATA, never rare.

What this is not

Not an annotator, and not a pathogenicity call. It decides only whether a frequency question can honestly be answered.
